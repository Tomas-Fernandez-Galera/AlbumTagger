# Nombre e identidad del proyecto

AlbumTagger es el nombre utilizado por Tomás Fernández Galera para identificar este proyecto. No se afirma que sea una marca registrada.

La licencia GNU GPLv3 aplicada al código fuente no concede permiso para utilizar el nombre AlbumTagger, su icono ni su identidad visual de una manera que pueda hacer creer que una versión modificada o redistribuida es la versión oficial.

Se permite mencionar AlbumTagger de forma veraz para describir el origen del código, la compatibilidad o la relación de una obra derivada con el proyecto original.

Las versiones modificadas deben indicar claramente que no son oficiales y quién las ha modificado. Si pueden confundirse con la versión oficial, deberán utilizar un nombre y una identidad visual distintos.
